# Kairu Compose client fork

This source tree contains Kairu SMP additions under `minecraft/src/main/java/uk/kairu/client`.
The Compose UI engine and supporting source originate from Polyfrost OneConfig and remain subject to its included LGPL-3.0 licence and additional terms. Existing copyright and licence notices are retained.

The generated Kairu client is a Kairu-branded Fabric client plus the required Kairu Compose runtime. It is not a separately-installed OneConfig mod. Build with `Build-Kairu-Compose-Client.ps1`; copy both JARs from `output` to the client mods folder.
